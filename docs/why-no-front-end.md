# Views without an application front end

The free base supports a strategy lead working through an agent and a database. It stores the decisions, calculations and evidence references behind the weekly meeting. HTML views and documents are read-only snapshots for review and printing.

A purpose-built screen gives people mobile entry, offline capture, shared editing, drag-and-drop planning and guided permissions. Those features are not included here. Neither are automatic KPI feeds, a notification service, arbitrary Cascade formula parity or hosted access management. Enterprise DNA agrees and builds the missing workflow before replacing it in a managed installation.

The database is the product. Claude Code, Codex, OpenCode or Cursor is the door. AGENTS.md and CLAUDE.md give each runtime the same rules. No personal-information deletion, email or external submission runs from this package.
